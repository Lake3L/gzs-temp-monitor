# GZS Temp Monitor

Небольшое приложение для контроля температуры на объекте вроде ГЗС. Оно хранит помещения, датчики, показания и события в SQLite, показывает состояние датчиков в окне PyQt6 и умеет выгружать отчёты в Excel и PDF.

Сейчас датчики работают через встроенный симулятор. Это позволяет проверить сценарии нагрева, охлаждения, скачка температуры и потери связи без подключённого оборудования.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

В Linux или macOS команда активации окружения будет такой:

```bash
source .venv/bin/activate
```

При первом запуске приложение создаёт локальную SQLite-базу и предлагает добавить демонстрационные помещения и датчики.

## Что есть в проекте

- мониторинг показаний датчиков;
- предупредительный и критический пороги;
- журнал событий и подтверждение событий оператором;
- настройка помещений, датчиков и уведомлений;
- отчёты за день, неделю, месяц или произвольный период;
- экспорт отчётов в `.xlsx` и `.pdf`.

## Структура

- `database` — модели и работа с SQLite;
- `simulator` — источник тестовых показаний;
- `core` — сбор данных, анализ и отчёты;
- `ui` — окна и элементы интерфейса;
- `main.py` — запуск приложения.

Проект учебный: отправка писем пока имитируется записью в журнал, а реальное подключение промышленных датчиков требует отдельного адаптера.
